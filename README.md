# Client-side todolist - React

Esta serviço é um sub module de uma aplicação, que tem como objetivo construir uma todo-list. O app também está configurado para rodar em containers, utilizado a tecnologia do Docker para manter tudo em ordem.
As informações de como subir a aplicação inteira estão descritas no README.md da [aplicação principal](https://github.com/matheusfaggi/todolist) .
